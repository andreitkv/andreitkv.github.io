Mocap retarget workflow 01:28

Problem → solution

Match the skeletons.
Review the motion.

Different joint counts, proportions and bind directions make mocap transfer difficult to judge and slow to rebuild by hand. Retarget Tool uses known source and target profiles to fit the two skeletons and create a live, reversible preview.

01 / Recognise

Read both profiles

Identify the mapped target skeleton and the mocap hierarchy without relying on selection or fragile joint names alone.

02 / Fit

Match different bodies

Fit spine, neck, clavicles, arms and legs through temporary helpers while keeping the target joint lengths unchanged.

03 / Preview

Review before baking

Drive the target as a live retarget preview, inspect the motion, then use the established animation workflow for the final manual bake.

Technical notes Open details

Profile-driven mapping

Target roles come from the recognised character profile while mocap roles are stored independently, so different skeleton layouts can share one retarget workflow.

Reversible preview

The retarget system is built from temporary helpers and constraints. The source scene is not saved, and one Maya Undo removes the complete preview.

Motion Trail workflow 00:31

Problem → solution

See the motion.
Keep animating.

Judging an arc only from playback can hide uneven spacing and small direction changes. Motion Trail turns the selected control's movement into a clear viewport path that follows the real animated result.

01 / Create

Select and toggle

Create or remove trails from the current selection with one command, without changing the animator's selection.

02 / Read

Follow the real path

The trail samples world-space motion, including movement coming from parents, constraints, IK and animation layers.

03 / Adjust

Keep only useful controls

Choose the visible frame range and line width from two compact presets while the trail updates with animation edits.

Technical notes Open details

Reliable live updates

The tool listens for world-matrix, keyframe and animation-layer changes, then rebuilds the trail without permanent background polling.

Focused personal workflow

The interface keeps only the controls used in everyday animation: four range presets and three line-width presets.
